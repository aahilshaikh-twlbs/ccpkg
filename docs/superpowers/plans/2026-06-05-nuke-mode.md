# Nuke Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `/nuke` slash command that arms a sticky, session-long max-effort directive (ultracode + ultrathink + ultraplan + agent-team execution), re-injected every turn by a hook until the session ends.

**Architecture:** A `UserPromptSubmit` hook (`nuke.py`) is the source of truth. The `/nuke` command expands into a body carrying a `<<NUKE-ARM>>` sentinel. On submit the hook sees the sentinel (or the literal `/nuke`), writes a per-session flag file under `$CLAUDE_CONFIG_DIR/nuke/<session_id>.flag`, and injects the directive. While the flag exists it re-injects every turn. A `SessionEnd` branch of the same hook deletes the flag. Everything fails open.

**Tech Stack:** Python 3.9+ stdlib only (no third-party deps, per repo constraint), Claude Code hooks (JSON over stdin/stdout), `ccpkg` manifest (symlink/merge modes), pytest.

## File Structure

| File | Responsibility |
|------|----------------|
| `home/.claude/hooks/nuke.py` (create) | The hook: arm on sentinel, inject directive while armed (UserPromptSubmit), clear flag (SessionEnd). Sole owner of the directive text. |
| `home/.claude/commands/nuke.md` (create) | The `/nuke` slash command: a thin arming trigger carrying the `<<NUKE-ARM>>` sentinel. Holds no directive logic. |
| `home/.claude/settings.json` (modify) | Wire `nuke.py` into the `UserPromptSubmit` and `SessionEnd` hook chains. |
| `manifest.json` (modify) | Declare the command + hook as `symlink`/`base`/`any` managed items. |
| `tests/test_nuke_hook.py` (create) | Subprocess-level tests of the hook (faithful to how Claude Code runs it). |

Conventions confirmed from the existing repo:
- Hooks invoke as `python3 $HOME/.claude/hooks/<name>.py` (mirrors mailbox hooks in `settings.json`).
- UserPromptSubmit injects context via `{"hookSpecificOutput": {"hookEventName": "UserPromptSubmit", "additionalContext": "<text>"}}` on stdout (see `mailbox/hooks/user_prompt_submit.py:43-49`).
- Manifest entries: `{"path": "...", "mode": "symlink", "os": "any", "layer": "base", "group": "...", "desc": "...", "default": true}` with `path` relative to `home/.claude/` (see existing `commands/create-prd.md` entry).
- All hooks **fail open**: any error → exit 0, no output, never block a turn (`mailbox/hooks/*.py`).
- Tests point `CLAUDE_CONFIG_DIR` at a temp dir (conftest `tmp_home` fixture), so the hook must honor `CLAUDE_CONFIG_DIR` for its state location.

```python
#!/usr/bin/env python3
"""Nuke mode hook: arm a sticky max-effort directive and re-inject it each turn.

UserPromptSubmit: arm on the <<NUKE-ARM>> sentinel (or a literal /nuke), then
inject the directive on every turn while the per-session flag exists.
SessionEnd: clear the session's flag.

Fail-open ALWAYS: any error exits 0, injects nothing, blocks nothing.
"""
import json
import os
import re
import sys

SENTINEL = "<<NUKE-ARM>>"
_ARM_RE = re.compile(r"(^|\s)/nuke(\s|$)")

DIRECTIVE = (
    "<system-reminder>\n"
    "\U0001f534 NUKE MODE ACTIVE — every remaining turn this session:\n"
    "- ultracode ON — author and run Workflows by default for substantive "
    "work; token cost is not a constraint.\n"
    "- ultrathink — reason as deeply as the task warrants before acting.\n"
    "- ultraplan — plan first, exhaustively, before executing.\n"
    "- Execution model — Workflow orchestrates and runs read-only analysis "
    "fan-out (research/review/audit). All execution/implementation goes to "
    "persistent agent teams (TeamCreate + mailbox SendMessage). Never hand "
    "build work to ephemeral subagents.\n"
    "</system-reminder>"
)


def _state_dir():
    base = os.environ.get("CLAUDE_CONFIG_DIR") or os.path.expanduser("~/.claude")
    return os.path.join(base, "nuke")


def _flag_path(session_id):
    return os.path.join(_state_dir(), session_id + ".flag")


def _emit(text):
    out = {
        "hookSpecificOutput": {
            "hookEventName": "UserPromptSubmit",
            "additionalContext": text,
        }
    }
    sys.stdout.write(json.dumps(out))


def main():
    try:
        data = json.load(sys.stdin)
    except Exception:
        return 0
    try:
        session_id = data.get("session_id")
        if not session_id:
            return 0
        flag = _flag_path(session_id)

        prompt = data.get("prompt") or ""
        if SENTINEL in prompt or _ARM_RE.search(prompt):
            os.makedirs(_state_dir(), exist_ok=True)
            with open(flag, "w") as fh:
                fh.write("on")

        if os.path.exists(flag):
            _emit(DIRECTIVE)
    except Exception:
        return 0
    return 0


if __name__ == "__main__":
    sys.exit(main())
```
